---

Create the next ADR in `docs/adr/` using the template in `docs/adr/README.md`.

The title is whatever the user gave with the request; if none was given, ask
for one before creating the file.

- Number it as the next `NNNN` (look at the highest existing number in
  `docs/adr/`).
- Fill Context → Decision → Consequences concisely.
- Add a row to the index table in `docs/adr/README.md`.
