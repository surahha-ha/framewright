# 자막 글꼴 — 실려 있는 것, 추가할 것, 라이선스

자막의 「글꼴」 줄(ADR-0018)이 고를 수 있는 글꼴과, 그 글꼴을 우리가 어떤
조건으로 쓰는지, 나중에 더 넣을 후보를 적어 둔다. 글꼴 파일은 `public/fonts/`,
코드 쪽 표는 `src/engine/fonts.ts` 의 `SUBTITLE_FONT_FILES`.

## 우리 쓰임새가 라이선스상 무엇에 해당하는가

1. 글꼴 파일을 앱과 함께 **배포**한다(웹 서버가 `/fonts/*.ttf` 를 내려준다).
2. 글자를 영상에 **구워 내보낸다**(임베딩·출력물).
3. 사용자가 그 영상을 **상업적으로** 쓴다.

무료 글꼴을 고를 때는 셋 다 허용되는지 본다. 유료 글꼴은 1·2 가 별도 항목인
경우가 많다(「웹폰트」「영상·방송 임베딩」).

## 실려 있는 글꼴 (2026-09-15)

| id      | 라벨     | 글꼴               | 파일                                        | 라이선스 | 크기   |
| ------- | -------- | ------------------ | ------------------------------------------- | -------- | ------ |
| `brush` | 붓글씨   | Nanum Brush Script | `public/fonts/NanumBrushScript-Regular.ttf` | OFL 1.1  | 3.4 MB |
| `pen`   | 손글씨   | Nanum Pen Script   | `public/fonts/NanumPenScript-Regular.ttf`   | OFL 1.1  | 3.1 MB |
| `black` | 굵은고딕 | Black Han Sans     | `public/fonts/BlackHanSans-Regular.ttf`     | OFL 1.1  | 1.0 MB |

출처는 google/fonts 저장소(`ofl/<이름>/`)의 원본 TTF 그대로이고, 각 글꼴의
`OFL-<이름>.txt` 가 파일 옆에 있다.

**OFL(SIL Open Font License) 1.1 이 허용하는 것**: 배포, 임베딩, 상업 이용,
재배포. **조건**: 라이선스 문서를 함께 싣는다; 파일을 **수정하지 않는다**
— 수정하면 글꼴 이름을 바꿔야 한다(Reserved Font Name). 서브셋(자주 쓰는
2,350자만 남기고 잘라내기)은 수정에 해당하므로 **하지 않는다**. 서브셋은
드문 음절도 잃는데, 예능 자막은 그런 글자를 일부러 쓴다.

## 언제, 어떻게 받는가

- 앱 첫 로드에는 받지 않는다. 자막이 그 글꼴을 **처음 고르는 순간** 받고,
  저장된 문서를 다시 열어 재생 위치의 자막이 글꼴을 쓰고 있으면 프리뷰가
  받는다. 브라우저 캐시에 남으므로 두 번째부터는 받지 않는다.
- 받는 동안 프리뷰는 기본 글꼴로 그리고 상태줄이 「글꼴을 받는 중이에요」라고
  말한다. 도착하면 다시 그리고 「받았어요」라고 말한다.
- 내보내기는 계획에 나오는 글꼴을 전부 받은 뒤 첫 프레임을 그린다. 못 받은
  글꼴은 기본 글꼴로 그리고 완료 문장에 ⚠ 로 이름을 말한다.
- 글꼴은 항상 앱 자신의 origin 에서 받는다. 내보내기 시점에 외부 CDN 을
  부르지 않는다(오프라인·AWS 배포에서 같은 동작).

## 글꼴을 하나 더 넣는 법

1. 라이선스를 위 세 쓰임새에 대해 확인한다. 조건을 이 문서에 적는다.
2. 원본 파일과 라이선스 문서를 `public/fonts/` 에 넣는다(수정·서브셋 없이).
3. `src/engine/types.ts` 의 `SubtitleFont` 에 id 를 더하고,
   `src/engine/fonts.ts` 의 `FONT_IDS` · `FONT_LABEL` · `FONT_HINT` ·
   `SUBTITLE_FONT_FILES` 에 한 줄씩 더한다. `family` 는 파일 안의 family 이름과
   같아야 한다.
4. `src/engine/fonts.test.ts` 를 돌리고, `e2e/subtitle-font.spec.ts` 의 라디오
   목록에 라벨을 더한다.
5. 아래 「추가 후보」에서 그 글꼴을 지우고 위 표로 옮긴다.

유료 글꼴을 넣을 때의 추가 결정: 글꼴 파일이 사용자 브라우저로 내려가므로
「웹폰트 배포」가 허용되는 상품이어야 하고, 사용자가 내보낸 영상의 상업 이용까지
허용되어야 한다. 이 둘이 안 되는 상품은 우리 구조에서는 쓸 수 없다.

## 범위 밖 (이 문서가 답하지 않는 것)

- 글꼴 크기·자간 조절, 글꼴 견본을 라디오에 그리기, 내려받기 진행률 표시.
- woff2 변환: 용량은 줄지만 파일을 바꾸는 일이라 OFL 의 이름 변경 조건이
  따라온다. 필요해지면 그때 결정한다.
